## The system (how it must look)
- Each screen's root: `<div className="cd-page">`, starting with `<div className="cd-page__head"><div><h1 className="cd-h1">Title</h1><p className="cd-sub">One line</p></div>{actions}</div>`. Panels are `cd-panel` with `cd-panel__head` (title as `<h2 className="cd-h2">`) and `cd-panel__body`. Use `cd-grid` with `cd-span-*` for multi-column layouts.
- Surface ladder: paper, then one `cd-panel`, then hairlines or a `cd-well` inside. **Never a panel or bordered box inside a panel** (Floor 4). No `shadow-*` glows, no `backdrop-blur`, no gradients (`bg-gradient-*`), no decorative blurred blobs. A border OR a shadow, never both.
- Figures: a `cd-stats` row (set `style={{ "--cols": n }}`) with `cd-stat`, `cd-stat__label`, `cd-stat__value cd-num`, not a grid of KPI cards. Tables: `cd-table-wrap` + `cd-table` (rules only, sentence-case heads). Prefer a table over cards for lists of records.
- Charts (data-viz.md): one accent series (`var(--color-accent)`), every other series in `var(--color-ink-2)` / `var(--color-muted)` or a lightness step of the accent; no glow or drop-shadow on marks; gridlines `var(--color-rule)`; a pie, donut or gauge becomes a stacked horizontal bar or a labelled bar list of the same numbers. Bars start at zero. Text never wears the series colour.
- Controls: `cd-btn` (one filled primary per screen or dialog), `cd-btn--quiet` (secondary), `cd-btn--ghost`, `cd-btn--danger` (destructive), `cd-btn--sm`; `cd-icon-btn` with an `aria-label`; `cd-seg` for 2 to 5 options (state via `aria-pressed`), `cd-tabs` for tabs (`aria-selected` / `role="tab"`); fields `cd-field` > `cd-label` + `cd-input` / `cd-select` / `cd-textarea` + `cd-help`; checkboxes `cd-check`; toggles `cd-switch` (an `<input type="checkbox" role="switch">`; if the existing toggle is a button with custom logic, keep the button and its handler and style it with `aria-pressed`). Every `<button>` gets an explicit `type`. Status: `cd-badge` + `--signal` / `--success` / `--danger` / `--warn`; banners `cd-alert`; empty `cd-empty`; loading `cd-skel` or `cd-spinner keep-motion`. Dialogs: `cd-overlay` > `cd-dialog`; toasts `cd-toast`.
- Type: Instrument Sans everywhere (inherited from `.cd-app`). Weights 400, 500 and 600 only (drop `font-black`, `font-extrabold`, `font-bold` becomes `font-semibold`). Sizes from `text-[length:var(--text-xs)]` style tokens or the kit classes; avoid `text-[10px]`/`text-[9px]` (nothing under 12px). Labels, table heads, badges, chips, tabs and nav: sentence case, **never `uppercase`, never `tracking-wide`/`tracking-wider`/`tracking-widest`** (Floor 67). `font-mono` only for codes, IDs and timestamps.
- Colour: only tokens. Allowed Tailwind colour names: `paper`, `paper-2`, `paper-3`, `ink`, `ink-2`, `rule`, `signal`, `signal-ink`, `signal-wash`, `focus`, `success`, `danger`, `warn`, `hover`, `selected` (e.g. `bg-paper-2 text-ink-2 border-rule`), or `[var(--color-*)]`. **Banned:** hex/rgb/rgba literals in classes or style props, Tailwind palette classes (`bg-red-500`, `text-emerald-400`, `bg-white`, `text-white`, `bg-black/40`, `text-gray-*`, `indigo`, `violet`...), the old `var(--primary)`/`var(--card-bg)`/`var(--foreground)` names (use the `--color-*` roles), `opacity`-built colours like `bg-[var(--primary)]/10` (use `bg-signal-wash` or `bg-selected`).
- Motion: state only. Never `transition-all` (use `transition-colors`, `transition-opacity`, `transition-transform`); never animate width/height/top/left; no `hover:-translate-y-*` or `hover:scale-*` on cards; no `animate-ping`, `animate-bounce`, pulsing dots; any remaining `animate-*` gets `motion-safe:` (spinners use `cd-spinner keep-motion`). No decorative status dots before labels.
- Icons: inline `<svg>` must carry `aria-hidden="true"` (or an `aria-label` if it is the only content of a control). Never emoji.
- Focus: every interactive element shows a focus ring. Kit classes have it; a custom clickable element gets `focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus`. Clickable `<div>`s keep their handlers; add `role="button" tabIndex={0}` only if a keyboard handler already exists, otherwise leave them and list them.
- Density: controls 30 to 36px, panel padding 16 to 24px, tables before cards. Layouts must collapse cleanly under 60rem (the kit grid does) and never scroll sideways except inside `cd-table-wrap`.
- Dark mode and tenant hues are automatic through the tokens; never add `dark:` colour classes.
